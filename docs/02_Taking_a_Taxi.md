# Taking a Taxi in Thailand

## Project: Lost in Translation — AI Thai Language Helper

## Purpose

This document helps foreigners communicate with taxi drivers in Thailand. It covers destinations, meters, journey questions, and basic directions.

## Common Phrases

Add an appropriate polite ending: ครับ for male speakers, or ค่ะ / คะ for female speakers depending on the sentence.

| English | Thai | Situation |
| --- | --- | --- |
| Go to [place], please. | ไป[สถานที่] | Giving a destination. |
| Go to Suvarnabhumi Airport, please. | ไปสนามบินสุวรรณภูมิ | Requesting an airport journey. |
| Go here, please. | ไปที่นี่ | Showing a location on a map. |
| Can you use the meter? | เปิดมิเตอร์ได้ไหม | Asking about the meter. |
| How much is the fare? | ค่าโดยสารเท่าไหร่ | Asking about the fare. |
| About how many minutes will it take? | ใช้เวลาประมาณกี่นาที | Asking about journey duration. |
| Can we take the expressway? | ขึ้นทางด่วนได้ไหม | Asking about the route. |
| Turn left, please. | เลี้ยวซ้าย | Giving a direction. |
| Turn right, please. | เลี้ยวขวา | Giving a direction. |
| Please stop here. | จอดตรงนี้ด้วย | Asking to stop at the destination. |

## Destination Information

Replace [สถานที่] with the destination name.

Examples:
- ไปสนามบินดอนเมือง — Go to Don Mueang Airport.
- ไปโรงแรม — Go to the hotel.
- ไปสถานีรถไฟ — Go to the railway station.

If the destination is a hotel or station, give its exact name or show its address on a map.

Suvarnabhumi Airport and Don Mueang Airport are different places. If a user says only “the airport,” the assistant should ask which airport they mean.

## Example Conversation: Airport Journey

Passenger: ไปสนามบินสุวรรณภูมิครับ
English: Go to Suvarnabhumi Airport, please.

Passenger: เปิดมิเตอร์ได้ไหมครับ
English: Can you use the meter?

Driver: ได้ครับ
English: Yes.

Passenger: ใช้เวลาประมาณกี่นาทีครับ
English: About how many minutes will it take?

## Example Conversation: Arriving

Passenger: เลี้ยวซ้ายครับ
English: Turn left, please.

Passenger: จอดตรงนี้ด้วยครับ
English: Please stop here.

Passenger: ขอบคุณครับ
English: Thank you.

## Example AI Response

User: How do I tell the driver to stop here?

Thai: จอดตรงนี้ด้วยค่ะ

English: Please stop here.

Usage: Say this when approaching a suitable stopping place. A male speaker can say จอดตรงนี้ด้วยครับ.

## How This Supports the Project

The assistant can help users explain destinations and translate short requests during a journey.

It should:
1. Ask for the exact destination if necessary.
2. Preserve hotel names and address information.
3. Distinguish translation from live travel advice.
4. Avoid inventing fares, travel times, toll amounts, or transport rules.

Asking to use the expressway does not establish whether tolls are included in a fare.
